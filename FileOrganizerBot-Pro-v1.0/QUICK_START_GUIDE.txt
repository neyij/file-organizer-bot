File Organizer Bot Pro - Quick Start Guide
==========================================

1. Installation
Simply extract this folder anywhere on your computer and run "File Organizer Bot.exe". No installation or Python setup is required.

2. Windows SmartScreen
Because this is an indie application, Windows Defender SmartScreen might show a "Windows protected your PC" warning the first time you run it. 
To bypass this:
- Click "More info"
- Click "Run anyway"

3. Custom Rules
To customize how your files are sorted, open the app, check "Clean up messy filenames", and click "Edit Custom Rules". 
This will open the rules.json file in this folder. You can define custom regex patterns and target folders.

Enjoy a cleaner desktop!
